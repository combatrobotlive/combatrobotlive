# Combat Robot Public Builder View 1.14

This small Streamlit app is the public, read-only viewer for Combat Robot Manager.
It does not contain your SQLite database or organiser controls.

## Files to put in GitHub

Upload these files to the root of a GitHub repository:

- `streamlit_app.py`
- `requirements.txt`

Do **not** upload any local database or publisher token.

## Deploy on Streamlit Community Cloud

1. Sign in to Streamlit Community Cloud with GitHub.
2. Choose **Create app** and select this GitHub repository.
3. Entrypoint: `streamlit_app.py`.
4. Open **Advanced settings** and paste the two lines generated by Combat Robot Manager's **Online sharing** page into **Secrets**.
5. Deploy.
6. Copy the resulting `https://...streamlit.app` address back into Combat Robot Manager.

The viewer uses only the Supabase publishable key. It has read access to active public competition snapshots and no organiser write access.
